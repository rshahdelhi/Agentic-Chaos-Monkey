# Agentic Chaos Monkey Presentation

[Open the editable presentation in Figma Slides](https://www.figma.com/slides/G2UgkQLf482Zjgij640H0n)

The ten-slide project deck covers:

1. The resilience and recovery problem
2. The governed incident lifecycle
3. Specialized agent responsibilities
4. The bounded faulty-v2 demo scenario
5. Safety controls and approval policy
6. The current prototype implementation
7. Automated validation results
8. Current readiness and the Kubernetes roadmap

The presentation describes the current project as an in-memory proof of
concept. Kubernetes adapters, persistent audit storage, and live telemetry
integration are identified as future work rather than completed capabilities.
